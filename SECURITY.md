# Security Policy

## Supported versions

This project is maintained in its current `main` branch. Security fixes are applied there first.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Instead, report vulnerabilities privately by emailing the maintainer at:

- `Nulerein@outlook.com`

Include:

- a clear description of the issue,
- reproduction steps if available,
- affected files or commands,
- and any suggested fix or mitigation.

We will acknowledge the report as quickly as possible and work toward a patch and disclosure timeline.

## Best practices

- Never commit real Discord tokens or API keys.
- Keep `.env` files local and not tracked in Git.
- Review any third-party libraries before upgrading them.
