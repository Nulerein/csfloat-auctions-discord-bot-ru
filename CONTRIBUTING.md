# Contributing

Thanks for your interest in improving CSFloat AuctionRadar Discord.

## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes and keep the scope focused.
4. Run the relevant checks locally.
5. Open a pull request with a clear description.

## Local checks

```bash
python -m py_compile discord_bot.py
```

## Coding guidelines

- Keep code readable and compact.
- Avoid introducing unrelated refactors.
- Do not commit secrets or real Discord tokens.
- Update documentation when behavior changes.

## Reporting issues

Use the GitHub issue templates for bug reports and feature requests. Include exact steps to reproduce, environment details, and any logs or screenshots that help debug the issue.
